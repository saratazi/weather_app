# 🌦️ Weather App

A modern and responsive Weather Application built with **HTML**, **CSS**, and **JavaScript**. It provides real-time weather information using the OpenWeather API and supports searching by city or using your current location.

---

## 🚀 Live Demo

🔗 **Live Website:**  
https://saratazi.github.io/weather_app/

---

## ✨ Features

- 🔍 Search weather by city name
- 📍 Current location weather (GPS)
- 🌡️ Real-time temperature
- 🤗 Feels like temperature
- 💧 Humidity
- 💨 Wind speed
- 👁️ Visibility
- 🌅 Sunrise & Sunset
- 🖼️ Dynamic weather backgrounds
- 🌤️ Weather icons
- 📱 Responsive design
- ✨ Modern Glassmorphism UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- OpenWeather API

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/saratazi/weather_app.git
```

2. Open the project.

3. Add your OpenWeather API key in `script.js`:

```javascript
const API_KEY = "YOUR_API_KEY";
```

4. Open `index.html` in your browser.
